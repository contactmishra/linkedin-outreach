# Outreach Desk dashboard (app/web/index.html)

Scope: the whole single-page dashboard. Mode: Operate. Second redesign, 2026-11-14: the owner asked for a bolder, animated page built on references from great product sites. That is the standing exit taken by the owner (the category canon played straight), so no roll ran. References chosen by the designer on the owner's delegation: Linear (dark, dense, quiet), Attio (crisp bordered surfaces), Superhuman (a review queue that feels fast). The earlier passport world is replaced; its one surviving idea is the approval seal.

Audience and job: one job seeker, ten minutes a day: read Claude's drafts, approve, press Run, and now watch Claude do the LinkedIn work without leaving the page.

## Direction contract

THESIS: A product-grade console where the owner approves and then watches the work happen. It refuses the generic admin template (grey cards, default blue, static panels) by holding Linear's level of finish and by making the run itself visible inside the page.

OWN-WORLD: Cool neutral surfaces in two themes (near-black indigo-tinted dark, crisp white light) with a theme switch; hairline borders instead of heavy shadows; 8px controls, 12px cards, 16px panels. One brand colour, an electric violet, for primary actions, selection and the logo. Each pipeline stage has a status glyph: a ring that fills as the person moves along, in the stage's colour. Approval is still a double-ruled green seal. The platform system sans (no web or locally installed face is named) with tight tracking on titles and tabular figures; the seal alone uses the inlined condensed face.

STORY: See what needs a decision, approve it, press Run, watch each message go out in the live panel, see the pipeline move.

FIRST VIEWPORT: Left rail 240px: logo and name, To do views with counts, People, Countries, send limits, theme switch. Main: header with view title, search, List/Board switch, Add person, Run top right. Pipeline strip of stage cells with status glyphs and counts. Work area: review cards or the people table, inspector docked right. When a run starts, a live panel slides in from the right and the work area narrows to make room.

SIGNATURE: The live run panel. A browser-framed live picture of Claude's LinkedIn tab, the current step with the message being sent, and a checklist that ticks off as each item completes; it can shrink to a small floating preview. Motion grammar: view transitions between views (the selected nav pill and the inspector move rather than swap), 160 to 260ms ease-out, the seal pressing down on approve, nothing looping except the live indicator.

FORM: seed: none (pinned) "build on top of some reference, you find online for great websites, with animations, smooth transitions, aesthetics" and, for the first-surface experience, "there is a sexy overlay in the webpage, where its automatically opening the profile of linked in, connecting or sending message" / "it slides partiallu and opens the dedicated page, and completes the work"

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
